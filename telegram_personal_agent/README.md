# Personal Telegram AI Agent v0.4

Персональный Telegram AI Agent для одного владельца с веб-панелью. Это **исходный проект**, не подключённый к вашему аккаунту и не развёрнутый облачный сервис.

## Запуск

1. Установите Python 3.11+.
2. Распакуйте архив и выполните `python -m venv .venv`.
3. Активируйте окружение: Windows `.venv\\Scripts\\activate`, macOS/Linux `source .venv/bin/activate`.
4. `pip install -r requirements.txt`.
5. Скопируйте `.env.example` в `.env` и заполните `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, `OPENAI_API_KEY`, `DASHBOARD_PASSWORD`. Получите Telegram API ID/Hash через my.telegram.org. Секреты никому не пересылайте.
6. `python login.py` — авторизация вашего Telegram-аккаунта, код/2FA вводятся **только локально**.
7. `python start.py` — запуск.
8. Откройте `http://127.0.0.1:8787`, логин `owner`, пароль из `.env`.
9. Проверьте стиль и режимы. Только затем включайте автоответы.

## Уведомления

Создайте отдельного сервисного бота через BotFather, укажите `NOTIFY_BOT_TOKEN` и `NOTIFY_CHAT_ID` в `.env`, включите уведомления в панели. Время отчёта и часовой пояс настраиваются.

## Проверка без Telegram

`python test_offline.py` запускает локальные тесты API с заглушкой OpenAI; нужен FastAPI и httpx. Проверка синтаксиса: `python -m compileall .`. Эти тесты не подтверждают подключение к Telegram или корректность ответов реальной модели.

## Безопасность

- Не публикуйте `.env`, файлы `*.session` и базу `*.sqlite3`.
- Не открывайте веб-панель в публичный интернет: для удалённого доступа нужен VPN или HTTPS reverse proxy с MFA.
- Автоматические ответы изначально выключены. Сначала проверьте их на тестовых контактах.
- Пользовательский Telegram-аккаунт может подвергнуться ограничениям за автоматизацию или нежелательные сообщения. Соблюдайте правила Telegram и согласие собеседников.
- Данные переписок отправляются в OpenAI API для генерации и анализа; учитывайте конфиденциальность.

Подробная матрица функций и ограничений — `FEATURES.md`.

## Улучшения v0.4

- Аналитика активности по дням, динамика отдельных контактов и история версий профиля в веб-панели.
- Предварительная детерминированная проверка ответа на повторы, чрезмерное количество вопросов, чувствительные обещания и длину; опасные черновики останавливаются и требуют решения владельца.
- История профилей остаётся предположительной: выводы ИИ не превращаются автоматически в подтверждённые факты.
- Дополнительные локальные тесты качества и аналитики.

Эта версия **не проверена на живом Telegram или OpenAI API** и не гарантирует отсутствие ошибок.

### Изменения v0.5

Запуск офлайн-проверок из каталога проекта:

```bash
python test_offline.py
python test_activity.py
```

Активное время — приблизительная оценка по промежуткам между сообщениями, а не точный хронометраж. Данные по дням доступны через `/api/analytics` и `/api/contact/{peer}/insights`.

### Новое в v0.6
В панели доступен раздел **«Группы и кандидаты»**: после подключения Telegram нажмите «Загрузить мои группы», выберите группу и запустите ручной просмотр последних сообщений. Найденные участники не получают сообщений; подготовка и отправка первого сообщения выполняются отдельно и только после вашего подтверждения. Раздел «Диагностика» показывает доступность базы, интеграций и число ожидающих согласований.

**Безопасность:** не выставляйте HTTP Basic-панель в открытый интернет. Для удалённого доступа используйте приватную VPN или HTTPS reverse proxy, защищённую аутентификацию и сетевые ограничения. Храните `.env`, SQLite и Telegram session только на доверенном устройстве. Автоматизация пользовательского Telegram-аккаунта может подпадать под ограничения Telegram.
