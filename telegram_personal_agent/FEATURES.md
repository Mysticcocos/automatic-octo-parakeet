# Personal Telegram AI Agent v0.4 — реестр функций

## Реализовано в исходном коде

- Подключение личного Telegram-аккаунта через Telethon (после авторизации владельцем).
- Автоматические ответы входящим контактам, изначально выключены.
- Личная защищённая HTTP Basic паролем веб-панель (только для локального доступа).
- Карточки контактов, история переписок, ручной перехват, пауза, возврат ИИ.
- Основная личность, пять параметров стиля, индивидуальные настройки каждого контакта.
- Контекст последних сообщений, профиль интересов, предпочтений и границ; анализ ИИ по мере накопления сообщений.
- Кандидаты долговременной памяти с ручным подтверждением, удаление памяти и локальных данных контакта.
- Дополнительный AI review перед отправкой, эскалация сомнительных ответов, fail-closed при ошибке проверки.
- Черновики и подтверждение первых исходящих сообщений владельцем, без массовой рассылки.
- Ограничения исходящих по дням знакомства и приблизительный счётчик активности, расписание по контакту.
- Остановка при выявленных оскорблениях, эскалация чувствительных тем.
- Сервисный бот уведомлений, настраиваемый фильтр категорий.
- Ежедневные отчёты по времени владельца и анализ заметок контроля качества с предложением изменений личности.
- Одобрение предложенных инструкций владельцем, версии личности и откат.
- Сводные метрики активности, качества и режимов, аудит событий.

## Частично или с ограничениями

- «Живое общение»: LLM с контекстом и дополнительными инструкциями; не гарантирует человеческое качество или идеальную аргументацию.
- «MAXIMUM» качество: вторая проверка LLM и набор ограничений, но это не формально верифицированная система и не гарантирует отсутствие ошибок.
- «MAXIMUM» самоанализ: отчёт и рекомендации по журналам; глубокая оценка каждого контакта требует достаточной истории и доступного API.
- Длительность общения: приблизительная оценка активных интервалов, не точный трекер времени разговора.
- Индивидуальные расписания в этой версии ограничивают ответы, не инициируют сообщения сами.
- Интеграция с реальным Telegram и OpenAI не проверена в этой среде: нужны секреты владельца и доступ к сервисам.
- Нет фонового поиска кандидатов в Telegram-группах: Telegram ограничивает подобную автоматизацию; предусмотрена очередь одобряемых исходящих черновиков.
- Нет облачного хостинга, TLS, MFA, распределённой очереди и production-hardening.
- Нельзя гарантировать соблюдение Telegram ToS или бесперебойную работу пользовательского аккаунта; автоматизация личного аккаунта может привести к ограничениям.

## Без операторов

Нет многопользовательской ролевой системы, операторских рабочих мест или академии. Приложение предназначено одному владельцу.

## Доработки v0.4 (проверяемые изменения)

- `/api/contact/{peer}/insights`: последние 30 дней активности, последние сообщения, оценки контроля качества и 10 версий профиля.
- `/api/analytics`: дополнительно динамика контактов и эскалаций по дням.
- Новые таблицы `daily_contact_metrics` и `profile_history`; обновление базы при запуске.
- `deterministic_review`: отдельный быстрый слой предварительной проверки до обращения к LLM-ревьюеру.
- Новые данные выведены в разделе «Память и расписание».
- Тесты проверяют API аналитики и блокировку повторяющегося ответа.

Не считать полностью решёнными: оценку качества на реальных диалогах, глубокое самообучение, поиск контактов, точный учёт активных минут, production-развёртывание и интеграционное тестирование с Telegram.

## v0.5 — реализованные исправления (24 октября 2026)
- Учёт приблизительных активных секунд теперь ведётся **по каждому контакту и дню в часовом поясе владельца**. Простой между сообщениями от 5 минут не считается активным временем; промежуток меньше 5 минут учитывается с ограничением до 120 секунд. Это оценка, не точное измерение внимания человека.
- Правила инициативных сообщений больше не блокируют обычные ответы на входящие сообщения.
- При обрыве Telegram-соединения предусмотрены повторные подключения с увеличением интервала ожидания (до 5 минут).
- Повторная проверка режима контакта перед постановкой ответа в генерацию после освобождения блокировки.
- API аналитики показывает приблизительное активное время по дням.
- Добавлен офлайн-регрессионный тест `test_activity.py`.

**Ограничения:** не проверено на реальном Telegram/OpenAI; полноценный поиск контактов в группах, сквозное end-to-end тестирование, серверное развёртывание и точное измерение активности не завершены. Проект не следует запускать с открытым доступом к панели без HTTPS и сетевых ограничений.

## v0.6 — октябрь 2026
- В личную панель добавлен раздел «Группы и кандидаты»: владелец вручную выбирает группу, в которой состоит, и просматривает активных участников недавнего обсуждения. Никаких автоматических сообщений, рассылок или обхода ограничений Telegram нет. Отдельный черновик первого сообщения по-прежнему требует подтверждения владельца.
- Добавлены API `/api/groups`, `/api/groups/scan`, `/api/groups/candidates`, `/api/groups/candidates/{peer}/decision` и защищённая `/api/diagnostics`.
- Первое исходящее сообщение при одобрении теперь дополнительно проверяется по установленному для контакта расписанию и лимитам.
- Дневной лимит ответов считается по календарному дню часового пояса владельца, а не по UTC.
- Добавлены локальные тесты новых API без подключения Telegram.

### Оставшиеся ограничения
Реальные Telegram/OpenAI-интеграции не протестированы без ключей владельца. Нет production-хостинга, HTTPS/MFA, гарантированной точности активного времени и формальной гарантии качества ответов. Обнаружение кандидатов — только вручную и по последним сообщениям, без фонового поиска и автоматического контакта.
